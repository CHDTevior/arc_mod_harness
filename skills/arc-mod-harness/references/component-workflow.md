# 按部件制作：2D、Tripo、可编辑模型与绑定

从已选定的游戏镜头目标和三视图拆件。每件先写用途：**设计参考 / 结构研究 / 候选几何 /
最终运行资产**。参考生成物不自动进入包。用项目 `component-plan.md` 记录；流程是按需选择，
简单的扣子、平面花纹或已有合适模型，不必为了用 Tripo 再生成一次。

## 按变形方式分件

| 部件 | 建模与参考路线 | 驱动与检查 |
|---|---|---|
| 发根、头壳、刘海大块 | 三视图定发际线、遮眼范围和体积；曲面/发束建模，可借相似模型结构 | 发根固定到正确头部驱动，刘海按需要蒙皮；查转头、眨眼与眉部遮挡 |
| 长发、马尾、长发束 | 单独画侧背的发束走向、分叉和厚度；生成物可作体积草稿 | 优先映射实际可用发骨链；检查原动画/物理驱动和运动余量，不能整束只绑头骨 |
| 紧身衣、上身衣片 | 从已定连续身体设计版型，留出厚度与余量；明确领口/袖口/下摆 | 身体表面权重迁移作起点，修腋下和肘部；用原动作验收 |
| 裙摆、披风、宽袖、垂带 | 独立结构图明确前后层、开口、翻边；必要时 Tripo 研究空间结构 | 优先复用目标实际服装骨链；仿真烘焙或新增驱动需先证明运行支持，不能默认会动 |
| 角、胸针、扣具、鞋饰等刚性件 | 独立 2D 多视图 → 简模或 Tripo 候选；尺寸/安装面单列 | 适合单骨/挂点的按刚体绑定；检查转体和接触，不要被周围皮肤权重拉软 |
| 眼、眉、嘴、眼镜 | 使用可控拓扑、独立控制组和真实相机投影 | 同步表情和遮挡；不使用生成脸的漂亮截图替代动画拓扑检查 |
| 翅膀、伴生体、召唤物、武器/特效 | 从实际资源与动作拆分；和主体设计一起确认保留/替换/局部改造 | 独立调查骨架、可见性、挂点与触发；不把藏网格等同于删除相关逻辑 |

“动作绑定”应拆成蒙皮、辅助骨/物理驱动、现有动作适配三项。头发绑到了骨骼上，不代表
那根骨骼会在游戏里运动；某段布料在 Blender 仿真正常，也不代表目标游戏会运行同样的仿真。

## 逐件参考循环

1. **提取设计。** 从已选目标中用 image edit 单独整理一个部件，保留整身安装位置图。
   必要时补同一尺度的正/侧/背视图；说明背面未知部分。不能把随意裁切的透视图冒充正交图。
2. **选最小试验。** 先选一个难把握、又能独立评价的部件；按现有授权和费用边界调用 Tripo。
   只研究几何时不必附加纹理、自动 rig 或格式转换；具体命令按宿主当前 Tripo 技能执行。
3. **检查真实三维。** 保存原生成文件、任务结果和输入哈希，查看正/侧/背/斜视的灰模、线框
   与材质图。检查粘连、孔、薄片、厚度、分件、UV、法线、面流；纹理画出来的凹槽不一定有几何。
4. **反馈到二维。** 渲染实际候选的多个视角，用 image edit 提出局部目标修正；把修正带回
   三维重建或再次生成。编辑图只是下一版目标，不能反过来充当旧模型通过的证据。
5. **决定使用方式。** 三选一：只学习形体/布线后重建；保留部分几何并修复/重拓扑；满足
   要求的刚性件直接作候选。记录来源与可复用范围，不把所有生成输出视为生产资产。
6. **适配目标 rig 和材料。** 校准尺寸、轴、安装面与 pivot；建立有效 UV/材质分区。软部件
   迁移并修正目标权重，刚性件保持硬形。Tripo 自动骨架/通用 retarget 不能直接证明兼容 GGST。
7. **分件验收再总装。** 本件灰模和动作先过关，再和身体、头、衣服、配件一起看原游戏镜头。
   单件不穿模不代表组合不穿模；重新检查邻近衣层和镜头遮挡。

**部件生成提示模板：**

> 依据已选角色参考，仅制作【部件名称】的设计图。保留其【轮廓、开口、厚度、花纹】，
> 正面/侧面/背面属于同一个部件；附整身上的位置示意。分离背景与人体，保持安装面方向。
> 不新增装饰，不把阴影画成几何缺口。未知背面为待选设计，不声称由原图恢复。

2D 定了目标仍可能存在结构矛盾，Tripo 多视图也可能生成粘连网格。遇到这种情况先修改
设计或采用手工建模，不无限追加生成次数。保留原输出，新增修正版，便于知道改的是哪里。

## 交接给总装的最小内容

本件输入/输出 ID 与哈希、目标参考版本、尺寸/轴、对象与材料列表、目标骨架/允许改动、
与身体的接缝或安装点、UV/权重变化、已看的实际姿态和镜头、尚未解决项。记录见
[交接模板](../templates/subtask-handoff.md)。不要让总装靠文件名中的 `final` 猜选中哪件。

## Chaos 的实际经验与新增建议

Chaos 有 imagegen 的 Source11 T pose 参考、完整 Tripo 候选及外套连通结构研究。
研究发现低 U 后领、袖根和翻边的结构有参考价值，但生成衣片无 UV/绑定且有孔和非流形边。
后续直接拼入上衣的试验仍有黑/杏色块和大幅边界变形，记录为暂停、未验收。
这说明“学习结构”有价值，“直接采用生成片”仍需完整检验。

**对每个饰物独立做 2D→3D→2D 循环，是本次给 harness 新增的改进路线**，不能写成 Chaos
当时每件都这样成功做过。具体历史边界见 [子任务 6](chaos-subtasks.md)。

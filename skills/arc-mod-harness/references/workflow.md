# 制作流程和回退路线

流程有依赖关系，但不要求所有 MOD 都重做身体。先做最低成本的原资源往返，确认能导出、
导入、Cook、装回，再投入完整造型。视觉参考与工具链调查可在同一任务中交替推进。

| 阶段 | 输入与产物 | 主要验收 | 失败时先回哪里 |
|---|---|---|---|
| brief | 愿望、保留项、镜头 → 简短制作说明 | 作者能指出最终差异 | 追问参考，不先堆模型 |
| reference | 插画/类似模型 → 三视图、结构图、来源清单 | 正侧背一致；补全有明确选择 | gen/edit 概念或实际供体研究 |
| base | 原 rig、连续裸模/rest pose → 未穿衣身体 | 头身、肩颈、胯、手脚、连续曲面 | 回到完整底模，避免窄带拼接 |
| wardrobe | 已定身体 → 服装、头发、鞋、饰品 | 层次、厚度、动作余量 | 衣服形体或权重，勿改坏身体 |
| rig | 原 bind、原动作 → 骨语义映射、实际姿态 | 关节折叠、枪/手接触、头切换 | rest/坐标/层叠规则，再看蒙皮 |
| look | 实际 shader → 材质、UV、所有配色 | 实际引擎里肤感、黑线、轮廓、透明度 | 查原材质图，不套 PBR 惯例 |
| voice | 源声音及事件映射 → 替换资源、试听与触发记录 | 音色、时长、响度、语言、事件覆盖 | 事件映射和编码，不只调音高 |
| motion | 当前候选 → 原相机视频、关键帧、投影 | 表情、遮挡和过渡；带实际对应语音 | 小范围目标求解，再连续检查 |
| package | 选定运行资产 → 依赖闭包、Cook 包、清单 | 无漏项/测试覆盖物；解包与源一致 | 引用关系、装配版本与挂载路径 |
| runtime | 最终包 → 安装记录、实际游戏录制 | 原游戏镜头、语言、颜色、冲突 | 按最终包复现，不拿旧渲染顶替 |
| delivery | 通过或标注限制的包 → 试用/发布材料 | 接收者可安装、知道限制和回滚 | 交付清单和清洁环境测试 |

## 身体与衣服

对综合改模，先建立连续、可变形的裸体基础模型（nude rest pose）。它是检查解剖比例和
关节的制作底层，不意味着最终 MOD 必须裸体。可用无细节人体代理进行早期审查。不要为了
省一次建模，把两个比例不同的躯干用很窄的一圈网格接起来，再让接带承受所有扭转。

原网格的 UV 拆点不等于破洞；几何连续、法线连续和权重连续是三件事。先确认源曲面的
连通性，再适配整段胸腹腰髋。身体定型后做衣服；仍保留全身体源，只在最终导出副本按
实际遮挡删除必要区域。衣服不能靠静态遮住裂缝来通过验收。

## 绑定和动作适配

优先保持目标游戏骨名、层级、rest 矩阵和武器接口。类似模型的同名辅助骨未必语义相同。
记录哪些骨属于变形、表情、衣服、道具或游戏逻辑。先复现原角色动作，再把新模型放入
同一个测试；区分蒙皮问题和动作比例问题。

比例改变造成肩臂过宽时，局部缩网格不一定能修好。可做视觉动作适配，但必须守住原枪
挂点、手接触、根运动、时间、事件、曲线及不相关动画。对旋转/平移/缩放分别列 allowlist；
读回真正的引擎和 cooked 数据检查，不只看 Blender 曲线存在。

先检查待机、下蹲、伸展、弯肘/膝、抬臂、持武器，再看必杀、入场、胜利和表情切换。
high/low 头、不同角色层叠和缺失轨道必须按该游戏实际规则处理。未发现规则时停在该项
诊断，继续别的独立工作，不能默认为单位矩阵或借另一个头的动画。

## 用小实验替代长时间盲改

每次循环写五行：症状 → 假设 → 最小改动 → 能区分假设的检查 → 结果/下一步。
先渲染最能暴露问题的一帧及其邻帧；过了再完整渲染。对共享贴图先试默认色和两个极端色，
确认机制后批量验证所有目标配色。最终受影响动画连续检查，不能把早期抽样写成逐帧检查。

只有出现新变化、失败或未解决顾虑时才扩大验证。把已通过模型不停重建、不断重录不变
视频会浪费时间，也容易把旧成果误装回去。每次交接用明确文件和哈希，不用“latest/final2”。

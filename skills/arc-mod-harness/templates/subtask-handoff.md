# 子任务交接

- 本件目标、选定参考 ID、所属候选版本：
- 输入 ID/哈希、原工程基线：
- 输出 ID/哈希、对象名、材料槽、UV、坐标单位与轴：
- 实际做了什么；保留了什么：
- 源 skeleton/rest、绑定/驱动要求、接缝或挂点：
- 测试动作、原 key/输出帧映射、相机和可复现入口：
- 证据类型：AI 概念 / DCC / 原生引擎 / 实机（逐项说明）：
- 实际看过的帧与未覆盖内容：
- 失败假设与下一条路线：
- 总装需要重烘焙/重导入/同步的依赖：
- 人类决定原话、来源（无决定留空）：
- 当前状态：研究参考 / 未验收候选 / 已接受本件 / 已整合（选真实状态）：

历史案例数字和候选状态不能当成本件验收。一个子任务通过不代表总装、Cook 或实机通过。
